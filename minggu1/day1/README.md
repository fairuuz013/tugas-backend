Tugas 1 – Penjelasan Frontend, Backend, dan API

Dalam tugas ini, gue bakal ngejelasin hubungan antara frontend, backend, dan API dengan cara yang lebih rapi, jelas, dan gampang banget dipahami. Biar lu kebayang, sebuah aplikasi itu nggak cuma soal tampilan doang, tapi ada banyak proses di belakang layar yang kerja bareng biar semuanya jalan mulus. Nah, tiga bagian utama yang paling sering lu denger adalah frontend, backend, dan API.

Pertama, kita bahas frontend dulu. Frontend itu bagian aplikasi yang langsung dilihat dan dipake sama user. Tugasnya nampilin informasi, gambar, style, tombol, warna, layout, dan segala hal visual lainnya. Frontend bisa dibilang kayak kasir di restoran. Kasir nggak masak makanan, tapi mereka yang nampilin menu, nerima pesanan, dan bantu pelanggan milih makanan. Sama kayak aplikasi, frontend cuma nampilin data yang udah disiapin backend. Dia jarang ngurus logic berat, karena fokus utamanya adalah bikin tampilan yang enak dilihat dan mudah digunakan.

Sekarang kita masuk ke backend. Kalo frontend adalah kasir, backend itu koki di dapur. Backend ngurus proses inti aplikasi seperti ngelola data, ngelakuin perhitungan, ngatur database, ngejalanin sistem login, keamanan, transaksi, dan semua hal yang nggak keliatan oleh user. Backend itu penting banget karena dia yang memastikan aplikasi bekerja dengan benar. Jadi, meskipun user nggak pernah ngeliat backend, semua fitur keren yang aplikasi punya biasanya hasil kerja backend.

Nah, biar frontend dan backend bisa komunikasi, ada yang namanya API. API ini mirip kayak pelayan di restoran. Pelayan yang bolak-balik bawa pesanan dari pelanggan ke koki, lalu nganterin makanan dari koki balik ke pelanggan. Dalam aplikasi, API yang bawa permintaan data dari frontend ke backend, lalu balikin hasil proses backend ke frontend. Tanpa API, frontend dan backend kayak nggak bisa ngomong satu sama lain.

1. Frontend

Frontend fokus banget ke tampilan dan interaksi user. Mereka bikin struktur halaman, style, animasi, dan bikin aplikasi terasa nyaman. Logic yang di-handle biasanya cuma logic yang berhubungan sama tampilan.

2. Backend

Backend fokus pada logic aplikasi, sistem data, keamanan, dan alur kerja aplikasi. Dia ngatur cara aplikasi berjalan tanpa harus mikirin tampilan sama sekali.

Kesimpulannya, frontend, backend, dan API itu saling terhubung dan saling butuh. Tanpa salah satu dari mereka, aplikasi nggak bakal jalan dengan bener. Mereka kayak tim restoran yang solid: kasir, pelayan, dan koki—kerja bareng demi hasil terbaik.
